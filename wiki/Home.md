# MMM-BSR-Trash-Calendar Wiki

This Wiki contains the operational documentation for the MagicMirror² module that shows
upcoming Berlin BSR and optional Berlin Recycling pickup dates.

- [Installation](Installation) — install the module in MagicMirror².
- [Configuration](Configuration) — configure BSR, categories, Berlin Recycling, and privacy.
- [Troubleshooting](Troubleshooting) — diagnose address, cache, refresh, and portal issues.
- [Releasing](Releasing) — publish a version and synchronize this Wiki.

For the source code, issue tracker, and a concise project overview, visit the
[repository](https://github.com/mgummich/MMM-BSR-TrashCalendar).
